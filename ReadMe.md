## Purpose

This is the Road to 56 companion of Sandbox Mode Overhaul. It aims to make non-historical play more interesting and unpredictable, while still keeping AI behavior coherent and purposeful.

Enable it **with** The Road to 56. Do **not** enable vanilla Sandbox Mode Overhaul at the same time.

## Development Note

This mod is being developed alongside [HSL](https://github.com/evgeny-sobol/hsl) (HoI4 Scripting Language). Source lives in `.hsl` / `.include` / `.hml`; compile against the subscribed Road to 56 workshop copy, never write into that folder.
